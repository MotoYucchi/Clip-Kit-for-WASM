# 実機検証チェックリスト（Phase 1: MVP）

実機テストの結果に応じて、推奨容量・解像度制限は `src/config/deviceLimits.ts` で一括調整できます。

## 対象環境マトリクス

| デバイス | OS / ブラウザ | 確認対象 |
| --- | --- | --- |
| **iPhone** | iOS Safari / Chrome for iOS | 写真ライブラリ読込、HEVC/HDR/回転メタ動画、Web Share API 保存、ボトムシート片手操作、セーフエリア（ノッチ） |
| **Android** | Android Chrome / Firefox | ファイル選択、44px タップ領域、Wake Lock 稼働、ダウンロード保存、メモリ警告 |
| **iPad** | iPadOS Safari | タブレット判定（デスクトップ UA 含む）、上下レイアウト、重い処理の警告表示 |
| **PC** | Chrome / Edge / Firefox / Safari | 3ペイン表示、ドラッグ&ドロップ、ST/MT 自動切替、前後比較プレビュー、Ctrl+Z / Ctrl+Shift+Z |

## 機能・品質チェック項目

### 1. 読み込み・メタデータ・iPhone 動画互換
- [ ] MP4 / MOV / WebM / MKV / AVI / 音声ファイルが読み込める
- [ ] iPhone 撮影の縦動画（回転メタデータ付き）がプレビューと出力で同じ向きになる
- [ ] iPhone HEVC / HDR 動画でメタデータ（解像度・回転・HDR・VFR）と適切な警告が表示される
- [ ] 複数音声トラック動画でトラック数と各トラックの言語/コーデックが表示される

### 2. 加工・書き出し
- [ ] 単一区間カット（高速カット `-c copy` と正確なカット）が期待通りの秒数で出力される
- [ ] 圧縮プリセット 4段階（高画質/標準/小容量/最小容量）で出力サイズが変化し、変換前推定サイズと大きく乖離しない
- [ ] WebM 選択時に H.264 が自動で VP9 へ補正され通知が表示される
- [ ] 解像度変更（1080p/720p/任意倍率/カスタム）および 画面比率 3モード（引き延ばし / レターボックス任意色 / ブラー背景）が正常に出力される
- [ ] 0.25x / 0.5x / 2x / 4x 速度変更で音声ピッチが保たれ、音ズレしない
- [ ] 回転・反転・クロップを同時に適用しても1回のエンコードで正しく反映される
- [ ] 音声抽出（MP3 / AAC / WAV / FLAC / Opus）およびミュート（全体 / 区間 / トラック削除）が動作する
- [ ] 静止画書き出し（PNG / JPEG）が指定時刻のフレームを出力する
- [ ] メタデータ削除 ON の出力ファイルに GPS / 撮影機器メタデータが残らない

### 3. デバイス制御・UX・法務
- [ ] スマホで 4K / H.265 / AV1 が非対応（無効＋理由表示）になっている
- [ ] 200MB 超のファイルをスマホで読み込んだ際に警告バナーが表示される
- [ ] 処理中の進捗バー・残り時間表示・Wake Lock 案内・キャンセル（Worker 再初期化）が正常に動作する
- [ ] タブを再読み込みした際に「前回の編集設定を復元しますか？」バナーが表示される
- [ ] `licenses.html` に全利用ライブラリのライセンス表記とプライバシー説明が正しく表示され、日英切替できる
- [ ] 開発者ツールの Network タブで、動画・音声データが外部サーバーへ送信されていないことを確認できる

### 4. Phase 2 拡張機能チェック項目
- [ ] BGM 音声ファイルを追加し、音量・オフセット・トリム・フェードイン/アウト・ループ設定でミックス出力できる
- [ ] ブラウザのマイク録音（MediaRecorder）で録音した音声がトラックとして追加され、FFmpeg で統一変換される（Safari MP4 / Chrome WebM 両方）
- [ ] 波形表示（元動画 & 追加音声トラック）がタイムライン上に描画される
- [ ] 「別トラック保持」で MP4 / MKV へ書き出した際、VLC 等で複数音声トラックが切り替えられる
- [ ] `loudnorm` ON で極端に小さい/大きい音声トラックが自然な音量に正規化される
- [ ] タイムラインでクリップ分割・複製・並べ替え・別動画ファイル連結（異なる解像度/FPS）が音ズレなく結合される
- [ ] 用途別プリセット（Discord 10MB / 25MB 等）と 2パスエンコードで目標サイズ内に収まる（スマホでは 2パスが非対応理由付きで無効）
- [ ] VFR→CFR（`-vsync cfr`）と HDR→SDR トーンマッピング（iPhone HDR 動画）が正常に動作する
- [ ] Undo / Redo、プロジェクト設定 JSON 保存/読込、PC キーボードショートカット（`Space`, `J/K/L`, `I/O`, `←/→`, `S`, `?`）が動作する
